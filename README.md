# 作品① · 最小 RAG 问答（带引用 + 评测）

> 状态：**占位仓库**。W9–W11 才开始写代码，现在先建仓。

## 这个作品要做什么

一个能"查资料再回答"的问答系统：

1. 把文档切块 → 转成向量 → 存进向量库
2. 提问时先检索相关片段，再让大模型基于片段回答
3. **每条答案标出来源**（文件名 + 段落号）
4. **查不到就说"没找到"**，不硬编
5. 自带评测：15 条以上问题的 Recall@5 + 3 类失败案例

## 计划的技术栈

- Python + FastAPI（服务）
- 向量库：Chroma 或 FAISS
- Embedding：待定（本地模型或 API）
- 大模型：DeepSeek API（function calling 已在本机跑通过）
